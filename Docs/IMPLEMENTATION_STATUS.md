自动化测试验证以下契约：

- 连续请求提示不会自动允许完整答案；否定表达不会被当作答案授权。
- 超出提示权限的模拟模型回复不进入用户可见结果。
- 模型异常不切换离线演示，原始服务异常不写入学习状态。
- SQLite 关闭并重新打开后，题目、代码、提示状态和反思能恢复。
- CLI 退出后可在另一个进程恢复会话。
- 新代码有独立哈希和检查结果，旧尝试保留。
- 语法检查不会执行有文件写入行为的用户代码。
- 重新导入题面不修改已有会话中的题目快照。
- 不存在的题目不会由模型补全，不受信任链接不访问网络。
- 实际 LangChain 模型适配器能解析模拟供应商的结构化工具调用并记录 token 元数据。
- DeepSeek 官方域名的模拟请求带有关闭思考模式的参数；其他兼容域名不受该参数影响。配置示例采用官方模型名 `deepseek-flash`。
- 用模拟容器观测验证两题的宿主判定逻辑，包括合法下标、节点身份、环、错误协议和运行异常。
- 用固定的可信进程探针验证宿主监督器的 stdout/stderr 上限、超时和输入传递；这些探针不是宿主执行用户提交。
- `/test` 不调用模型、不升级提示级别；新版本不会沿用旧版本的通过状态。验证历史保存在对应尝试中。
- 缺失 Docker 或未启用验证时，不会改为宿主执行。

上述自动化测试是工程契约测试，使用模拟响应，不调用付费 API。另用本地 DeepSeek 配置进行了少量真实诊断请求，复现了“请求成功但 H1 回复被 H0 策略拦截”的问题；修复后，相同中文求助通过一次完整工作流调用返回，`last_error=None`、提示级别 H1、未展示完整答案。该单例验证不代表固定多轮教学质量评估完成。
