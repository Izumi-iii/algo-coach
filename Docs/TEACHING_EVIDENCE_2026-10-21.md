# 教学证据检查

## 本轮实现

在现有教学重试流程中增加确定性的输入/预期核验与历史引用核验。实现位于 `src/algo_coach/teaching_evidence.py`，不运行用户代码，不调用第二个模型作为裁判。CLI 和 Web 复用同一工作流；检查摘要附在教学回复末尾。

### 结构化样例

`TeachingReply.counterexamples` 最多包含 2 条，每条包含 `kind`、`inputs` 和 `expected`：

```json
{
  "kind": "candidate",
  "inputs": {"nums": [3, 3], "target": 6},
  "expected": [0, 1]
}
```

- 仅对与内置题面或远程审核哈希完全匹配的第 1、25 题启用判定，不能只凭题号套用规则。
- 第 1 题校验整数与范围、不同下标、唯一解及正确下标，允许输出顺序不同；布尔值和数字字符串不能冒充整数。
- 第 25 题校验节点值、`k` 与正确值序列，保留不足一组的尾部。该检查不验证节点身份、是否有环或实际指针行为。
- 独立计算限制在最多 200 个元素。超过核验范围或题面无适配器时明确 `unsupported`，不假定正确。
- `kind=constraint_example` 专门用于说明输入违反约束，只确认输入不合法，不检查其预期输出，也不将它称为合法反例。
- 正文中明确写出的 `nums=[...]` / `head=[...]` 需有对应结构化样例；紧随的 `target` / `k` 也须一致。代码围栏中的实现字面量不作为样例提取。

状态 `input_expected_checked` **仅证明输入和预期自洽**，不证明当前代码失败。当前样例恰好匹配已有 `/test` 失败报告时，还需同时核对实际代码字节哈希、题面哈希、输入及预期，再标记 `execution_evidence_matched=true`。此过程只读取原报告，不新增执行，不改写用户验证状态。

### 历史引用

`history_sources` 向模型提供最近 16 条实际可见消息的消息标识、角色、原文及原有用户代码版本标签。消息标识绑定全历史中的位置及原消息内容哈希；追加消息不改变旧标识，内容或版本变化会改变标识。模型能引用的文本与原有每条消息的 16000 字符截断范围一致。

`TeachingReply.history_citations` 最多包含 3 条，每条必须提供 `message_id`、逐字 `quote` 和来源的 `user_code_hash`。检查消息存在、引用片段存在且版本标签原样匹配；旧消息没有标签时保持未知，不从当前代码推断。可识别的直接历史引文缺少来源时也会被拒绝。

核验后显示实际来源角色和版本，避免只依赖模型的自然语言描述。`source_matched` **不证明历史诊断正确，也不证明引用与当前结论相关**。自由文本转述、角色归因和没有明显引号的历史叙述仍未获得通用语义验证。

### 拒绝、重试与留痕

不合法输入、错误预期、伪造引文或版本不匹配会进入原有最多两次尝试的纠正流程，持续失败则保存用户输入并返回失败状态，不展示被拒绝的助手草稿。重试反馈是应用生成的规则说明，不直接转存供应商异常。

`LearningState.teaching_evidence` 保存请求 ID、当前代码哈希、结构化检查、是否实际展示及拒绝规则。新字段缺失的旧会话可正常继续。检查摘要与原回复一起持久化；成功引用和测试报告消息均保留当时的代码版本标签。引用附件仍经过原有提示权限检查，不能绕过代码披露限制。

评估采集器同步记录结构化字段、检查结果和新拒绝规则，最终状态快照也包含证据记录；未把新增检查伪装成此前评估中已经存在的判定。

## 真实模型首测与已知回归

冻结 `evaluation/evidence_cases_v6.jsonl` 后运行 1 个开发场景、3 个模型步骤：代码分析、结构化反例、历史引用。题型仅为第 1 题，不是盲测或完整教学质量评估。两次运行都显式禁用 Docker，不调用 LeetCode。

| --- | --- |
| `20261021T021710Z-0174d9c1` | 4 次调用，23523 tokens；样例步骤因正文遗漏结构化样例、重试预期下标算错而失败；引用步骤成功。场景自动契约未通过。 |
| `20261021T021817Z-240e586d` | 明确正文样例登记与算术纠正要求后复跑，5 次调用，30370 tokens；样例步骤仍因非法输入或未登记的废弃候选失败；引用步骤重试后成功。场景自动契约仍未通过。 |

两批源码/提示不同，保留首测，不拼接为同一版本通过。累计 9 次调用、53893 tokens，金额未知。样例与引用检查能拦截已声明的不成立证据，但模型仍会在正文试错、混淆唯一解，或在只要求引用时重复展开旧任务。保留失败，不通过放松约束换取通过率。本轮仅做代码和输出的 AI 辅助检查，没有新增正式人工评分。

关键限制：自由文本中的所有算术、具体反例与结构化字段是否语义一致、引用是否支持结论，尚没有通用证明；同一输入的模型预期正确，也可能无法触发当前代码错误。真实用户体验仍受保守拒绝影响。本轮不宣称教学已经全面可靠。

脱敏运行摘要与检查状态见 [证据记录](evidence/teaching-evidence-2026-10-21.json)。原始可见响应、消息和会话只保存在被忽略的本地评估目录。
